## Project Overview

DevTalks is a modern, full-featured developer community platform built with Next.js 15, Firebase, and TypeScript. It provides a space for developers to share knowledge, discuss projects, and engage with the community.

### Key Features

- **Forum System** - Create posts, comment, reply, and engage with the community
- **Blog Platform** - MDX-based blog with syntax highlighting and rich content
- **Project Showcase** - Display and manage development projects
- **User Authentication** - Firebase-based auth with email/password and Google sign-in
- **Admin Dashboard** - Comprehensive content management system
- **Real-time Updates** - Live comments and post updates
- **Theme System** - 12 beautiful color palettes (light and dark themes)
- **Responsive Design** - Mobile-first, fully responsive UI
- **SEO Optimized** - Meta tags, sitemap, and structured data
- **Image Management** - Upload and manage images with Firebase Storage
- **Upvoting System** - Community-driven content ranking
- **Announcement System** - Admin announcements and notifications

## Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Database**: Firebase Firestore
- **Authentication**: Firebase Auth
- **Storage**: Firebase Storage
- **Styling**: Tailwind CSS
- **Content**: MDX (Markdown + React)
- **Testing**: Jest + React Testing Library
- **Deployment**: Vercel (recommended) or Firebase Hosting
